## Features
- **Responsive 16:9 Slide Canvas**: Dynamic scaling to fit any viewport, projector, or tablet seamlessly.
- **Evidence Lightbox**: Interactive click-to-zoom on all Google Maps, review, and photo evidence.
- **Full Scoring Logic**: Live breakdown of review counts, owner responses, recency, Google posts, photos, star rating, NAPWH, and business attributes.
- **Navigation**: Arrow keys (`←` / `→`), spacebar, on-screen controls, swipe gestures, and `F` for fullscreen mode.
